# Nulls Brawl Version Tracker

A community-maintained reference for tracking Nulls Brawl releases, major updates, brawler changes, platform availability, compatibility notes, and important changes over time.

This repository is designed to keep release-related information organized so players can quickly understand what changed, which platforms are affected, and where to find the appropriate installation resources.

## What this tracker covers

The tracker may include:

- Current and previous releases
- Major update changes
- Newly added or changed brawlers
- Android compatibility notes
- iPhone and iPad availability
- PC availability
- Installation and update-related changes
- Important feature changes
- Known compatibility issues after major updates

## Android download

Players looking for the current Android package and installation information can use the [Nulls Brawl APK](https://null-brawl.org/) page.

The main website is the download-focused resource for the current Android release, installation requirements, and related setup information.

This GitHub repository does not host APK files, application packages, or executable downloads.

## Brawler changes

Major updates can introduce new brawlers or change the available roster.

The complete roster, roles, and character information are maintained in the [Nulls Brawl Brawlers](https://null-brawl.org/brawlers/) guide.

Keeping the roster information on its dedicated page allows this repository to remain focused on version changes and release tracking.

## iPhone and iPad

Installation on iPhone and iPad follows a different process from Android and may require additional setup.

Players looking for the current iOS package, installation methods, compatibility information, and setup instructions can use the [Nulls Brawl for iOS](https://null-brawl.org/nulls-brawl-for-ios/) download page.

Compatibility and installation requirements can change after system updates, so current instructions should be checked before installing or updating.

## PC

Using Nulls Brawl on a computer may require additional software or configuration depending on the system.

The current download options, requirements, and setup process are covered on the [Nulls Brawl for PC](https://null-brawl.org/nulls-brawl-for-pc/) page.

PC compatibility can vary depending on the operating system, emulator, hardware resources, and other local configuration.

## Update tracking

When a significant release becomes available, this repository can record:

1. Release period
2. Major changes
3. New or changed brawlers
4. Platform compatibility changes
5. Installation-related changes
6. Known issues reported after release

## How this repository is maintained

Only confirmed information should be added to the tracker.

Version-specific details should be updated when a new release is confirmed rather than guessed in advance. Platform instructions should also be reviewed when installation requirements or compatibility conditions change.

## Repository purpose

This repository is a lightweight public documentation resource for Nulls Brawl version history, update tracking, and platform compatibility.

It does not distribute installation files. Download-related pages are linked only where they are relevant to the platform or installation context.

## Update history

Confirmed release notes and important changes will be documented here as they become available.
