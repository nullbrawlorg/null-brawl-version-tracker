# Nulls Brawl Version Changelog

This changelog is maintained as a chronological record of confirmed Nulls Brawl releases and significant changes.

The purpose of this file is to make it easier to see how the project changes over time without mixing historical information with current installation or platform documentation.

## Tracking policy

Only confirmed changes should be recorded here.

Entries may include:

- Release or update period
- New brawlers
- Important feature changes
- Platform compatibility changes
- Installation-related changes
- Major fixes
- Known issues discovered after an update

Information should not be added based only on rumors, predictions, or unconfirmed announcements.

## Entry format

Future releases should follow this structure:

### Release date or period

#### Added
- Newly introduced features or content

#### Changed
- Important changes to existing features

#### Platform notes
- Android compatibility changes
- iPhone and iPad compatibility changes
- PC compatibility changes

#### Known issues
- Confirmed issues affecting players

## Current status

The repository is currently being organized into a structured version-tracking reference.

Confirmed release entries will be added here as new information becomes available.

## Maintenance notes

Historical entries should remain in this file after newer releases are added.

If information changes because of a later update, a new changelog entry should be created instead of silently rewriting older release history.

This helps preserve an accurate chronological record of changes.
